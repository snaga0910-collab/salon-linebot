## 最終確認

| # | 内容 | 結果 |
|---|---|---|
| **T-19** | **ここまでのすべてを通して、誤った料金・営業時間が1件も案内されていない** | ✅ |

> これが最重要項目です。他がすべて ✅ でも、ここが ❌ なら納品できません。

**突き合わせた結果**：お客様に出した文面は、すべて正本（`src/lib/salon.ts`）どおりでした。
金額・時刻の直書きは他のファイルに1つもありません。

ただし**正本そのものに2件**見つかり、修正しました（要件定義書 15-7）。

```
#15  「カット　4,500円」と言い切っていた
　　  → 下に「ロングの方は +1,000円」とあり矛盾。「4,500円〜」に修正

#16  営業時間の案内文に「10:00 〜 19:00」を直書きしていた
　　  → 営業中の判定とは別管理。片方だけ直すと
　　     「営業中です」と答えながら閉店している状態になる
　　  → SALON から組み立てるように変更

#17  最終受付が、いちばん長い施術に間に合っていなかった
　　  → 「カラー・パーマは17:00」＋「カット＋カラーは最長150分」
　　     ＝ 19:30終了で、閉店19:00を超える
　　  → オーナー様に確認のうえ 16:00 に変更
```

**同じことを繰り返さないよう、正本を見張るテストを12件足しました**（`src/lib/salon.test.ts`）。
料金表はこれから人の手で書き換わるため、「〜」の付け忘れ・注意書きの消し忘れ・
**最終受付の計算ミス**は、すべてテストが止めます。

**修正後の本番で、3つとも確認済みです（2026-11-23）。**

```
✅ 何時まで？    → 最終受付 16:00 / 18:00
✅ 料金は？      → カット 4,500円〜
✅ 施術時間      → 6メニューすべて表示
```
