# 1. ふだんの使い方

## 1-1. お客様から問い合わせが来たとき

LINEに、こういう通知が届きます。

> 📷 **［スクリーンショットを貼る：問い合わせの通知（対応済みボタン付き）］**

| 色 | 意味 |
|---|---|
| **赤い文字** | **お急ぎです**（予約の変更・キャンセル・お困りごと） |
| 黒い文字 | 急ぎではありません |

### すること

```
① お客様にご返信する（いつもどおりLINEで）
② ［✅ 対応済みにする］を押す
```

**②を押すまで、このシステムは「まだ終わっていない」と覚えています。**

### 押さなくても大丈夫です

夜に通知が来て、そのまま寝ていただいて構いません。
**翌朝、まとめてお知らせします。**

お客様には、その場で「オーナーが確認してご連絡します」と自動でお返事が届いています。
**深夜でも、お客様を待たせません。**

---

## 1-2. 朝のまとめが届いたとき

毎朝**8時台**に、残っているものだけお知らせします。

> 📷 **［スクリーンショットを貼る：朝のまとめ通知］**

```
未対応のお問い合わせが2件あります
```

**残っていない朝は、何も届きません。**
毎朝必ず通知が来るわけではないので、「届かない＝何もない」とお考えください。

---

## 1-3. いま何が残っているか見たいとき

下のメニューの **［未対応の一覧］** を押します。

> 📷 **［スクリーンショットを貼る：オーナー側のリッチメニュー（6ボタン）］**

> 📷 **［スクリーンショットを貼る：未対応の一覧］**

2件以上残っているときは、**［すべて対応済みにする］** も出ます。

### ⚠️ 一覧を見たあとに新しい連絡が来ていたら

**その1件は消えません。** わざと残しています。

一覧を見たあとに届いたものを一緒に消してしまうと、
**見ていないお問い合わせが消えてしまう**からです。

```
3件すべてを対応済みにしました。
そのあとに届いた1件は残してあります。
```

こう出たら、もう一度 ［未対応の一覧］ を押してご確認ください。

# 2. お休みを出す

## 2-1. 今日・明日のお休み

**ボタン1つです。**

| ボタン | 動き |
|---|---|
| **［本日休業］** | 今日お休みのお知らせを出す |
| **［明日休業］** | 明日お休みのお知らせを出す |

> 📷 **［スクリーンショットを貼る：本日休業を押したあとの画面］**

## 2-2. 日付を指定したいとき

**［日付を指定］** を押すと、入力欄に「休業 」と入った状態になります。
**そのうしろに、お休みの内容を続けて入力してください。**

```
休業 11/28（金）は臨時休業をいただきます
休業 12/29〜1/3は年末年始のお休みです
```

**文のなかの日付を読み取って、その日まで自動で出します。**

## 2-3. ⭐️ お知らせは、自動で消えます

**ここが一番お伝えしたいところです。**

```
12/29〜1/3 と入れた場合
　　↓
1月3日まで表示
　　↓
1月4日になると、ひとりでに消える
```

**取り消しの操作は要りません。** 消し忘れは起こりません。

> ❗️ 以前のやり方では、「お休みのお知らせを消し忘れて、
> 営業中なのに休みと表示され続ける」ことが起こり得ました。
> **消し忘れても壊れない形**に作り直してあります。

出ているあいだは、**毎朝のまとめに「いまこのお知らせが出ています」とご報告します。**

## 2-4. 早めに取り下げたいとき

**［休業を取り消す］** を押します。
（予定より早く営業できることになった場合だけ使います）

# 3. お客様に何が見えているか

## 3-1. 自動で答えること

| お客様が聞いたこと | 自動で答えます |
|---|---|
| 営業時間・定休日 | ○ |
| メニューと料金 | ○ |
| 施術にかかる時間 | ○ |
| 最終受付 | ○ |

> 📷 **［スクリーンショットを貼る：お客様側のリッチメニュー（6ボタン）］**

**答えるのは、この4つだけです。**

## 3-2. 自動で答えないこと

| お客様が聞いたこと | どうなるか |
|---|---|
| 空き状況・予約 | 「確認してご連絡します」と返し、**オーナー様へ通知** |
| 予約の変更・キャンセル | 同じ。**赤い文字**で通知 |
| 髪のお悩み・ご不満 | **内容にはいっさい触れず**、オーナー様へ通知 |
| 駐車場など、伺っていないこと | **推測で答えず**、オーナー様へ通知 |
| スタンプ・お写真だけ | 内容は読めないので、**そのままオーナー様へ通知** |

### なぜ答えないのか

**間違ったことを答えないためです。**

とくに髪のお悩みは、**システムが何か答えた時点で事故になります。**
「髪が傷みました」に自動で返事をしてはいけないので、
**内容に触れず、オーナー様にそのままお渡しする**作りにしています。

# 4. 料金は「〜」付きで出ます

お客様には、こう表示されます。

```
・カット　4,500円〜
・カラー　6,000円〜

※ ロングの方は +1,000円を頂戴しております
※ カットとカラーを同時にご利用の場合、お安くなります
※ 髪の長さや状態で変わりますので、
　 正確な金額は施術時にご案内いたします
```

**わざと「〜」を付けています。**

「4,500円」と言い切ると、**ロングのお客様には違う金額を伝えたことになり**、
その場で「言っていた金額と違う」というお話になってしまいます。

# 5. 営業時間・最終受付

いまこの内容でお客様にお伝えしています。

| | |
|---|---|
| 営業時間 | 10:00 〜 19:00 |
| 定休日 | 毎週水曜日 |
| 最終受付（カラー・パーマ・カット＋カラー） | **16:00** |
| 最終受付（カット・前髪カット・トリートメント） | **18:00** |

### 16:00 にした理由

```
カット＋カラー … 最長150分
16:00 + 150分 = 18:30   閉店に間に合う ○
17:00 + 150分 = 19:30   閉店を過ぎる  ✕
```

**17:00でお受けすると、閉店を30分過ぎます。**
お客様をお待たせし、オーナー様の残業にもなるため、16:00にしています。

> この「最終受付 ＋ 施術時間 ≦ 閉店」は、**システム側で毎回自動チェックしています。**
> 将来メニューの時間が延びても、計算が合わなくなればこちらで気づけます。

前回いただいた紙のメニュー表と1行ずつ見比べて反映します。

# 7. お知らせを友だち全員に送りたいとき

**このシステムには入っていません。**
LINEの管理画面（LINE Official Account Manager）から送っていただく形になります。

### ⚠️ 送る前に、通数をご確認ください

| | 通数 |
|---|---|
| LINEの無料枠 | **200通／月** |
| 友だち320名へ1回送ると | **320通** |

**1回で無料枠を超えます。** 超えると有料プラン（月5,000円・税別）が必要になります。

### お休みのお知らせなら、通数を使わずに出せます

**［本日休業］や［日付を指定］で出すお知らせは、1通も使いません。**
営業時間を聞かれたお客様に、その返事のなかで表示されるためです。

```
年末年始のお休み → 2章の［日付を指定］で出す（0円）
セール・新メニュー → LINEの管理画面から配信（通数がかかる）
```

送り方は、操作のご説明（30分）であわせてご案内します。

# 8. 困ったとき

## 8-1. 変な返事をしていた

```
① その画面を撮る（スクリーンショット）
② お客様が送った文面も一緒に送る
③ 長倉へ送る
```

**この2つがあると、原因がすぐ分かります。**
「なんか変だった」だけだと、同じ状態を再現できないことがあります。

> ❗️ お客様への謝りの連絡は、**オーナー様からお願いします。**
> システムからは何も送りません。

## 8-2. お客様に何も返ってこない

まずここを確認してください。

```
LINE Official Account Manager
　→ 設定
　　→ 応答設定
　　　→ 「Webhook」が ON になっているか
```

**OFFになっていると、システムに何も届きません。**
ONに戻すだけで直ります。分からなければご連絡ください。

## 8-3. あいさつが2通届く

**原因は決まっています。**

```
LINE Official Account Manager
　→ 設定
　　→ 応答設定
　　　→ 「あいさつメッセージ」を OFF にする
　　　→ 「応答メッセージ」も OFF にする
```

管理画面のあいさつと、システムのあいさつが**両方**出ている状態です。
納品時にOFFにしてお渡ししますが、**あとで誰かがONにすると再発します。**

## 8-4. お客様から「返事がない」と言われた

**［未対応の一覧］** を押して、そのお客様が残っていないか確認してください。

残っていなければ、**［✅ 対応済みにする］を押したあとに、ご返信を忘れている**可能性があります。
ボタンは「システム上の記録を閉じる」だけで、**お客様への返信はされません。**

---

# 9. やらないでいただきたいこと

| | 理由 |
|---|---|
| 「あいさつメッセージ」「応答メッセージ」をONにする | **あいさつが2通届きます**（8-3） |
| 「Webhook」をOFFにする | **何も届かなくなります**（8-2） |
| LINEの管理者権限を手放す／変更する | **システムが止まります。** 変更前にご連絡ください |

**この3つ以外は、何を触っても壊れません。** 安心してお使いください。
