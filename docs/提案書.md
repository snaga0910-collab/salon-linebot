## 2. 伺った課題

ヒアリングで、佐藤様はこのようにおっしゃいました。

> 「買い物中にLINEが来たら『帰ってから確認してご連絡しますね』と返すんですけど、**それを忘れてしまうことがあって**。翌朝『すみません!!』と謝ることが月に何回かあります。」

> 「電話は出られないときは出なくていいので、そこまで苦ではないんです。**LINEは既読がついてしまう**ので、読んだのに返していないのが気になって……。」

> 「時間というより……**夜、返信のことが頭から離れないのが嫌**なんです。」

### 私が理解した、本当の課題

ご相談の文面には「問い合わせが多くて大変」とありました。しかしお話を伺ううちに、**件数そのものは問題ではない**とわかりました。

| | |
|---|---|
| ❌ 表面的な課題 | 問い合わせが多く、返信に時間がかかる |
| ✅ **本当の課題** | **すぐ答えられない問い合わせを抱えたまま夜を過ごし、既読のプレッシャーを感じ、ときどき返信を忘れて謝ることになっている** |

そう判断した理由は3つです。

| 伺った事実 | 意味 |
|---|---|
| 既存のお客様が8割、新規は月2〜3人 | **料金を尋ねる方は、実はそう多くない** |
| 問い合わせは夜21〜23時に集中 | 返せない理由は施術中ではなく**営業時間外** |
| 「LINEは既読がついてしまうから気になる」 | 負担の正体は**作業量ではなく、気持ちの重さ** |

> **ですので、単に「よくある質問に自動で答えるbot」を作っても、佐藤様の悩みは半分しか解決しません。**
> ご提案するのは、**24時間お客様を待たせず、かつ、対応が終わるまで佐藤様に代わって覚えておくシステム**です。

## 3. 解決すること・解決しないこと

### ✅ 解決すること

| | 内容 |
|---|---|
| 1 | **夜中の問い合わせにも、3秒以内に自動で一次返信が入る**（お客様を待たせない） |
| 2 | **返信が必要な件は記録され、済ませるまで消えない**（忘れられない） |
| 3 | **毎朝、開店前に「未対応◯件」がまとめて届く**（夜に覚えておかなくてよい） |
| 4 | 営業時間・メニュー・料金・所要時間は自動で回答される |
| 5 | 予約の変更・キャンセルは【至急】で即通知される |

### ❌ 解決しないこと（正直にお伝えします）

| | 内容 | 理由 |
|---|---|---|
| 1 | **「空き状況」に自動で答えること** | 予約が**紙の手帳**で管理されているため、システムから中身を見ることができません |
| 2 | **予約を確定させること** | ダブルブッキング防止のため、最終判断は佐藤様が行う方針で伺っています |
| 3 | **お電話の問い合わせ** | LINE以外は対象外です |
| 4 | **返信したら自動で「対応済み」になること** | **LINEの仕様上、実現できません**（下記） |

> **4について補足します。**
> 「佐藤様がお客様に返信したら、自動で未対応リストから消える」のが理想です。しかしLINEの仕組みを確認したところ、**システムが受け取れる通知は「お客様の操作」に限られており、佐藤様が送ったメッセージは一切届きません**。
> そのため、**［✅ 対応済みにする］ボタンを1回押していただく**運用になります。工夫で回避できる制約ではないため、先にお伝えしておきます。

## 4. ご提案するシステム

### お客様から見た動き

```
お客様：「来週の土曜って空いてますか？」（夜22時）
　　↓ 3秒以内
bot：「ありがとうございます。空き状況を確認して、
　　　 オーナーより改めてご連絡いたします。
　　　 （本日19時以降のお問い合わせは、翌営業日のご連絡となります）」
```

お客様は**深夜でも必ず返事を受け取ります。**「既読がついたのに返ってこない」がなくなります。

### 佐藤様から見た動き

```
夜22時　　LINEに通知が届く
　　　　　【空き状況の問い合わせ】みわ様「来週の土曜って空いてますか？」
　　　　　［ ✅ 対応済みにする ］
　　　　　→ 寝てしまって構いません

翌朝8時台　開店前に、まとめが届く
　　　　　「おはようございます。未対応のお問い合わせが2件あります。」
　　　　　① みわ様（11/7 22:14）「来週の土曜って空いてますか？」
　　　　　　［ ✅ 対応済みにする ］
　　　　　② たろう様（11/7 23:40）「明日の予約を変更したいです」
　　　　　　［ ✅ 対応済みにする ］
```

**夜のうちに覚えておく必要がなくなります。** 朝、手帳を見ながらまとめて返信し、ボタンを押すだけです。

### 機能一覧

| 分類 | 機能 |
|---|---|
| **自動で答える** | 営業時間・定休日／メニューと料金／所要時間 |
| **一次受けして伝える** | 空き状況／予約の変更・キャンセル（【至急】）／その他の質問 |
| **触れずに伝える** | クレーム・髪のお悩み相談 |
| **忘れないようにする** | 未対応リスト／毎朝のまとめ／通知への件数表示／「未対応」と送れば一覧表示 |
| **間違えないようにする** | 臨時休業モード（スマホから切替） |

> **料金の表示について**：ロング料金（+1,000円）とセット割引があるため、**「◯◯円〜」と幅を持たせ、注意書きを必ず添えます。**断定すると誤案内になり、かえってご迷惑をおかけするためです。
